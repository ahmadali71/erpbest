🏗️ Technical Architecture

  • Vite Dev Server with HMR

  • Node.js + Express.js 5
  • RESTful API Endpoints
  • Server-Sent Events (SSE) for Real-time
  • CORS Enabled
  • Error Handling & Validation
💾 Data Layer
  • MongoDB Atlas (Cloud)
  • Mongoose ODM
  • 12 Collections with Indexed IDs
  • Aggregation Pipelines for Reports

🗄️ Database Design

Collections

The system uses 12 MongoDB collections with custom string IDs for human-readable identifiers:

Custom ID Pattern

All collections use a custom id field (string) instead of MongoDB's default _id (ObjectId). Examples: prod-1, client-1, inv-1234567890

🔌 API Documentation

Base URLs

  • Backend: http://localhost:4000/api
  • Frontend Proxy: http://localhost:3000/api
  • Health Check: http://localhost:4000/api/health

Key Endpoints

Method Endpoint Description
GET /api/bootstrap Fetch all data in one request
GET /api/products List all products
POST /api/products Create product
GET /api/sales List all sales
POST /api/sales Create sale (auto-deducts stock)
POST /api/sales/:id/payments Record payment
GET /api/categories List categories
POST /api/reset Reset to demo data
GET /api/events SSE real-time stream

🚀 Setup & Deployment

Quick Start

1. Backend Setup

cd server
npm install
# Create .env file with MONGO_URI
npm run dev          # Development
npm run seed         # Seed demo data
npm start            # Production

2. Frontend Setup

cd client
npm install
npm run dev          # Starts on port 3000
npm run build        # Production build
npm run preview      # Preview build

3. Access Application

🌐 Frontend: http://localhost:3000

🔧 Backend API: http://localhost:4000

💚 Health Check: http://localhost:4000/api/health

Production Deployment

  • Backend: Deploy to Render, Railway, or Heroku
  • Frontend: Deploy to Vercel or Netlify
  • Database: MongoDB Atlas M0 Sandbox (Free tier)
